## 🚀 Featured Project

### [🛒 Instacart Real-Time Supply Chain Pipeline](https://github.com/ejabra/instacart-pipeline)

> A production-grade streaming pipeline processing **3M+ retail orders** in real time

| Component | Technology | Highlight |
|-----------|-----------|-----------|
| Ingestion | Apache NiFi | Visual flow, provenance tracking |
| Streaming | Apache Kafka | 12,000 events/sec throughput |

| Ops | Docker Compose | One command to launch 6 services |
